# 抗雄激素药物详解

抗雄激素是 MtF HRT 的重要组成部分。雌激素负责“补”，抗雄激素负责“减”——通过不同机制降低体内睾酮的作用，从而让雌激素更有效地发挥效果。

本页详细介绍四种常见抗雄激素药物——醋酸环丙孕酮、螺内酯、醋酸甲羟孕酮、GnRH 类似物，包括作用机制、常用剂量、副作用和注意事项。

::: danger ⚠️ 重要声明
本文仅为知识性指南，不构成医疗建议。所有用药方案、剂量选择均需由专业医生根据你的具体情况决定。请勿自行用药或照搬他人方案。
:::



## 抗雄激素的作用

雌激素本身具有一定的抑制睾酮的作用（通过负反馈调节下丘脑-垂体-性腺轴），但单靠雌激素往往不足以将睾酮抑制到女性范围。抗雄激素通过不同机制进一步降低睾酮水平或其作用：

- **抑制促性腺激素分泌**：如 GnRH 类似物、CPA
- **阻断雄激素受体**：如螺内酯、比卡鲁胺
- **抑制睾酮合成**：如 GnRH 类似物

::: tip 💡 是否需要抗雄激素
并非所有 MtF 都需要抗雄激素。如果雌激素剂量足够高，单靠雌激素也可能将睾酮抑制到目标范围。是否需要加用抗雄激素、选择哪一种，应由医生根据你的激素检查结果决定。
:::

## 一、醋酸环丙孕酮（CPA / 色普龙）

### 药品介绍

醋酸环丙孕酮（Cyproterone Acetate，俗称「色普龙」）是一种常用的抗雄药物，多用于男性前列腺癌的治疗、女性因高雄激素引起的痤疮、脱发等症状治疗，现为女性化激素治疗中使用最多的抗雄药物之一。

该药具有极强的孕激素作用，抑制卵巢功能，故也用于复方避孕药，如「达英-35」（Diane-35）。

### 常见产品

| 产品 | 简称 | 厂商 | 产地 | 规格 |
|------|------|------|------|------|
| Androcur（安得卡） | 土色 / 台色 | 拜耳 | 土耳其 / 台湾 | 50 mg × 50 片，100 mg × 30 片 |
| Androcur（德国） | 德色 | 德国拜耳 | 德国 | 10 mg × 45 片，50 mg × 50/100 片 |
| Siterone | 新色 | REX | 新西兰 | 50 mg × 50 片，100 mg × 50 片 |
| 华典 | 国色 | 武汉九珑人福药业 | 中国大陆 | 50 mg × 24 片 |

::: warning ⚠️ 关于“日色”
「日色」为**醋酸氯地孕酮**（Chlormadinone Acetate），同样具有抗雄激素活性，但**并非醋酸环丙孕酮**，请不要误用。
:::

### 用法与用量

::: tip 💡 适用范围
本章节内容仅适用于**同时使用雌激素**的女性倾向跨性别者。CPA 单药治疗时，即使在最大推荐剂量（10–12.5 mg/d）下，也不能实现睾酮水平的完全抑制；只有在和雌激素合用时方可实现。
:::

- **服用方式**：口服（无明显味道）
- **建议使用剂量**：**10–12.5 mg/天**

::: tip 💡 为什么是 10 mg/天
多项研究发现，在与雌二醇同时使用时 10 mg/天左右剂量**已可最大程度抑制睾酮**，且效果与高剂量一致。WPATH 最新发布的 SOC-8 亦建议 10 mg/天的剂量。

超出建议剂量会有更大的副作用与健康风险；低于建议剂量可能会使睾酮抑制效果不显著。
:::

**超低剂量方案**：进一步研究发现，每周两次 12.5 mg（等效约 3.5 mg/天）的超低剂量同样可以实现睾酮水平的充分抑制。在推荐剂量达到效果后，尽可能减少用量至 **5–6.25 mg/d**。由于研究资料有限，**暂不推荐减至 5 mg/d 以下**。

**实用切药技巧**：可用切药器将 50 mg 片切为四片（即每份 12.5 mg），每 1–3 日一服。

::: warning ⚠️ 如果 10 mg/天无效
若在推荐剂量（10 mg/天）下血清睾酮水平仍较高，请首先**检查雌激素血药浓度是否足够高**，必要时咨询相关专业医师。不要盲目增加 CPA 剂量。
:::

**其他建议**：
- 建议适量补充**维生素 B12**
- 停药时须**逐步减药**

### 副作用

::: danger ⚠️ 脑膜瘤风险
CPA 可能诱发**脑膜瘤**，风险与剂量和使用时长正相关。建议尽可能以更小剂量服用；如累积剂量已很大（高于 10 g），建议进行核磁共振扫描（MRI）。
:::

| 副作用 | 说明 |
|--------|------|
| **脑膜瘤** | 与剂量和使用时长正相关，累积剂量 > 10 g 建议 MRI |
| **精神疾病** | 可能导致抑郁风险升高；与维生素 B12 缺乏有关，建议适量补充 B12 |
| **高血压与高血糖** | 可能提高胰岛素抗性；糖尿病患者慎用，并发血管病变时禁用 |
| **血栓与乳腺癌风险** | 与雌激素合用时可一定程度提高其风险 |
| **高泌乳素水平** | 可明显增加泌乳素水平，且随剂量上升，严重时可引起垂体泌乳素瘤。应定期检查 |
| **肝毒性** | CPA 最严重的副作用，与剂量相关，表现为肝转化酶水平升高；严重时可引起肝衰竭甚至死亡 |

::: warning ⚠️ 肝功能检查
使用前应当检查肝功能，使用时定期检查。这是 CPA 使用中最不能省去的环节。
:::

**未明确**：过早导入 CPA（尤其高剂量）可能造成乳房发育不良。

- **有效成分**：醋酸环丙孕酮
- **化学名称**：6-氯-1α,2α-亚甲基-3,20-二孕酮-4,6-二烯-17α-醋酸酯
- **分子式**：C24H29ClO4
- **分子量**：416.94
- **CAS**：427-51-0

## 二、螺内酯片

### 药品介绍

螺内酯（Spironolactone；Antisterone；安体舒通）是保钾利尿药和醛固酮的特异性拮抗剂，用于治疗心衰、低钾血症和高血压等。但它也会**阻断雄激素受体**，从而具有抗雄激素特性。

不过，螺内酯本身**不会使睾酮降低**，其阻断效力**较弱**，需服用较大剂量方可充分起效。

### 常见产品

螺内酯片是国产仿制药，国内有多家厂商生产，常见规格为 20 mg。

### 用法与用量

- **服用方式**：口服
- **建议使用剂量**：**100–400 mg/天**，分多次服用

::: warning ⚠️ 剂量偏大
一般对 MtF 而言，和非注射途径的中等剂量雌二醇并用时，睾酮会有大幅下降，但仍高于女性正常范围。顺性别女性用于治疗雄激素相关症状时通常需要 50–200 mg/天，而 MtF 可能需要更高剂量（如 100–300 mg/天，乃至 400 mg/天）方可阻断剩余的雄激素，但随之而来的**尿频、高血钾等副作用可能会更严重**。
:::

**部分包装有令人不适的苦味。**

### 禁忌与注意事项

::: danger ⚠️ 禁忌症
**高钾血症患者切勿服用！**
:::

- **用药前及监测**：开始服药前血钾应**低于 5.0 mmol/L** 且肾功能正常；用药期间需定期监测血钾、血肌酐与尿酸水平
- **肝功能不全慎用**：肝功能不全（尤其是肝硬化）患者慎用，药物可能因引起电解质紊乱而诱发肝性脑病（昏迷）
- **合并用药慎用**：服用含锂药物（如碳酸锂）者慎用，螺内酯会降低锂排泄，需定期监测血锂浓度
- **饮食限制**：避免过多摄入高钾食物（如香蕉、紫菜、海带）及低钠富钾代用盐
- **用药禁忌**：不得同时服用其它保钾利尿药（如依普利酮、阿米洛利、氨苯蝶啶）或补钾制剂（如氯化钾、枸橼酸钾、门冬氨酸钾）
- **水分摄入**：服药期间应保持充足的水分摄入，避免血容量不足或脱水

|--------|------|
| **高钾血症** | 螺内酯最严重的副作用，可导致住院甚至死亡 |
| **尿频** | 常见 |
| **血压、血容积过低** | |

| **头晕、疲倦、困乏** | |
| **干皮、皮疹** | |
| **运动失调** | |
| **皮质醇水平升高** | |
| **胃肠道反应** | 恶心、呕吐、腹泻、胃痉挛、胃炎等 |
| **超敏反应** | |

::: warning ⚠️ 高风险因素
有以下风险因素者应慎用螺内酯：**高年龄（超 45 岁）、肾功能不全、与其它利钾药物合用、钾补剂的服用**等。必要时应监测血钾。
:::

## 三、醋酸甲羟孕酮（MPA / 安宫黄体酮）

### 药品介绍

醋酸甲羟孕酮（Medroxyprogesterone Acetate, MPA）是一种类固醇孕激素，具有抗促性腺激素作用，可以抑制体内雄激素水平。

在**无法获取到醋酸环丙孕酮（色普龙）时可作为替代品**服用，但效果稍差。

### 常见产品

| 品牌 | 厂商 | 规格 | 批准文号 |
|------|------|------|---------|
| 仙琚 | 浙江仙琚制药 | 2 mg × 100 片/瓶 | 国药准字 H33020715 |
| 创盈 | 北京斯利安药业 | 250 mg × 30 片/瓶 | 国药准字 H11021562 |
| 斯利安 | 南京臣功制药 | 2 mg × 100 片/瓶 | 国药准字 H41025341 |
| 法禄达（FARLUTAL） | Pfizer Italia | 500 mg × 30 片/盒 | H20140648 |

### 用法与用量

- **服用方式**：口服
- **建议使用剂量**：**有待验证**
  - 作为孕酮替代品使用：**5–10 mg**，抗雄效果可能较弱
  - 作为抗雄激素制剂使用：**推算 30–100 mg**

**达到效果的情况下尽量减少用量。停药时须逐步减药。**

### MPA 剂量与睾酮水平的关系

::: tip 💡 研究数据
不同剂量和给药方式下 MPA 对睾酮的抑制效果差异很大，以下是公开研究中报告的数据：

- **5–10 mg/天（舌下或肌注）**：睾酮平均降至 0.79 ± 0.18 ng/mL，略高于绝经前女性参考范围（0.1–0.55 ng/mL）
- **5–10 mg/天（肌注）**：睾酮平均下降 31%（范围 6–63%）
- **30 mg/天（口服）**：用于女性多毛症时，睾酮从 1.33 ng/mL 降至 0.57 ng/mL，降幅约 57%
- **60 mg/天（口服）**：用于男性性欲异常时，睾酮下降 50–75%
- **300–400 mg/周（肌注，等效 43–57 mg/天）**：血药浓度达 25 ng/mL 以上时，睾酮抑制率约 87–91%
:::

::: warning ⚠️ 剂量差异
口服吸收率低（0.6–10%），远不及注射剂的 100%，口服剂量需调整至注射剂的数倍方可达到相同效果。
:::

## 四、GnRH 类似物

### 简介

GnRH 类似物用于**青春期阻断治疗**。其分为激动剂和拮抗剂两种，作用于脑垂体 GnRH 受体；虽然激动剂治疗初期激素水平上升，但持续治疗后，二者疗效相当，均控制激素在青春期前范围内。

::: tip 💡 青春期的“暂停键”
在跨性别儿童中，GnRH 类似物治疗被比喻为「青春期的暂停键」，使青春期第二性征的发育暂停（如暂停乳房发育、阴毛生长、月经来潮，暂停阴茎阴囊增长和勃起等），使未成年跨性别者有更多时间去探索自我。

**若成年后仍希望进行性别转变**，则可接以性别肯定激素治疗；**若决定不进行转变**，停药后原有青春期会重新启动。
:::

### 对未成年的意义

在过去十年中，临床医生逐渐认识到性别焦虑 / 性别不一致的青少年的痛苦。在某些形式的性别焦虑 / 性别不一致中，心理干预可能是有用和充分的；然而，对许多青少年来说，**青春期的身体变化是难以忍受的**。

与在青春期的初期阶段之后很久才开始进行性别肯定治疗相比，**青春期早期进行青春期抑制会带来更好的心理和身体结局**。

- 符合性别不安 / 性别不一致诊断标准、满足治疗标准并要求治疗的青少年应该首先接受治疗以抑制青春期发育
- 建议在首次表现出青春期的身体变化后开始青春期激素抑制

### 对成年 MtF 的用途

对于完成了部分或全部青春期发育进程的跨性别女性，仍可将其作为**抗雄药物**使用，但**无法起到逆转已经完成的发育进程的效果**。

其优点在于一次用药的作用时间长，相对于 CPA 不易引起肝功能异常、泌乳素升高、抑郁、累积剂量过高导致的垂体瘤。

**缺点**：费用可能为其它抗雄药物的**数十倍**，且已经没有了“青春期阻断”这一特殊效果。

### 常见产品

目前国内有**亮丙瑞林注射剂**、**曲普瑞林注射剂**等可用。

### 用药细节

::: tip 💡 用药提示
本细节仅供参考，请根据自身实际情况咨询专业医生。

- **开始的两周内**：可能出现勃起现象更加明显的情况，这个情况是正常的
- **持续用药三个月左右**：可能出现睡不着（失眠）、没有食欲、情绪激动易怒的状况。这可能是因为**激素双低**——通俗点说就是雄激素被降下去，但是没有雌激素补充
:::

### 副作用

| 副作用 | 说明 |
|--------|------|
| **骨密度降低** | 应用期间影响骨量的累积，骨密度较同龄同性别人群偏低，身高增长减缓。文献报道停药后该效应可逐渐消失。应适当补钙、补充维生素 D |
| **抑制生殖器生长** | 抑制阴囊阴茎的继续生长，可能会对未来手术治疗产生潜在影响（该部位皮瓣面积不及一般人群） |
| **对脑发育的未知影响** | 如智力及认知发展等。近期研究认为认知能力未受到明显影响 |
| **其他** | 敏感、易怒、躁动、注射部位疼痛、痤疮、皮疹、头痛、体重增加等 |

### 价格参考

::: warning ⚠️ 费用高昂
用于该治疗的 GnRH 类似物价格较为高昂。例如在国内，亮丙瑞林注射剂集采中标价介乎 **907.13–1650 元**（中位数 1349.68 元）。

- 按最低价计，每月一次，一年总开销约**一万元**
- 按最高价计则**近两万元**

三个月一次的剂型在某些地区折算成本或更低，并且减少了打针的次数，是更佳选择。
:::

### 就诊建议

::: tip 💡 给未成年跨儿和家长
- **如果你是未成年跨儿**：请**要求家长陪同**前往专业的医院进行就诊
- **如果你是跨儿的家长**：请尽早陪同您的小孩前往专业医院就诊

推荐机构：
- 北医三院｜刘烨
- 复旦大学附属儿童医院
- 广州暨南一院｜高绿芬
:::

::: warning ⚠️ 多学科团队监测
儿童青少年处于生长和发育阶段，在监测发育变化（如性征表现、性激素水平）的同时，必须同时定期评估其生长情况（如身高、骨量、营养状态等）。因此，建议由**有经验的多学科团队**（包括内分泌、儿科、精神心理专业等）共同监测和指导。
:::

## 抗雄激素选择建议

| 场景 | 推荐 |
|------|------|
| 一般 MtF HRT | CPA 10 mg/天（最常用、证据最充分） |
| 无法获取 CPA | MPA 或螺内酯 |
| 吸烟者、有血栓风险 | 避免 CPA 与雌激素合用的大剂量方案，优先考虑经皮雌激素 + 低剂量 CPA |
| 有肝病史 | 避免 CPA，考虑 GnRH 类似物或螺内酯 |
| 有高钾风险 | 避免螺内酯 |
| 未成年（青春期阻断） | GnRH 类似物（亮丙瑞林、曲普瑞林） |

::: danger ⚠️ 不要叠加使用
**不要同时使用两种或以上抗雄激素**，除非医生明确指示。叠加使用会显著增加副作用风险，而不会带来成比例的效果提升。
:::
