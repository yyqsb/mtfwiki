# 概念

跨性别领域常用概念与社区术语速查。术语是帮助理解的工具，不是限制人的框架。


## 性别相关基础概念

### 性别认同

一个人内心认同自己是什么性别。

不取决于外表、穿着、身体特征、性取向、是否 HRT、是否手术或能否 pass。

### 性别表达

一个人通过穿着、发型、言行举止展现出来的性别风格。

可以是女性化、男性化或中性化。和性别认同是两件独立的事——表达女性化不代表认同为女性。

### 性取向

一个人喜欢什么性别的人，与自己的性别认同无关。

性取向描述“喜欢谁”，性别认同描述“自己是谁”，两者没有任何关系。

### 出生时被指派性别（AGAB）

出生时被外界非自愿指定的性别。

- **AMAB**：出生时被指派为男性
- **AFAB**：出生时被指派为女性

描述的是一次出生分类，不代表一个人的实际性别。

### 顺性别 / 跨性别

- **顺性别**：性别认同与出生时被指派性别一致
- **跨性别**：性别认同与出生时被指派性别不一致

### GD（Gender Dysphoria）

性别不安 / 性别焦虑。指身体特征、社会角色、称呼或他人认知与自身性别认同不一致时产生的心理痛苦。

不是所有跨性别者都会经历 GD，它不是身份成立的必要条件。

### “生理性别”

::: danger ⚠️ 这不是一个准确的性别概念

:::

人体中不存在一个可以直接读取、天然统一并决定性别的“生理性别”属性。染色体、性腺、外生殖器、激素水平、第二性征等维度各自独立发育，表现也是连续的。“男性身体”“女性身体”是在连续谱系上人为划出的区间。

这个词在实际使用中，表达的是**说话者根据自己的身体标准，对他人作出的性别分类**。同一个长期 HRT 的跨女，依据染色体可能被称为“生理男性”，依据激素状态可能被称为“生理女性”——判断结果随标准变化，说明它是主观分类而非独立事实。

需要讨论身体时，直接使用“染色体”“激素水平”“生殖结构”“第二性征”或“出生时被指派性别”更准确。

## 跨性别方向分类

- **MtF / 跨女**：出生时被指派为男性、性别认同为女性。是否 HRT、是否 SRS、是否出柜、是否 pass，都不影响身份成立。
- **FtM / 跨男**：出生时被指派为女性、性别认同为男性。
- **Non-binary / 非二元**：性别认同不属于男性或女性。MtX 指出生指派为男性，FtX 指出生指派为女性。

## 容易混淆但不是跨性别的身份

::: warning ⚠️ 重要区分
以下身份的性别认同与出生指派性别一致，或不属于跨性别范畴，不应与跨性别混为一谈。
:::

- **CD（异装者）**：穿另一性别服装，性别认同与出生指派一致。穿衣是表达或爱好，不是性别认同。
- **男娘 / 伪娘**：外表、穿着、声音或角色女性化的男性。性别认同为男性或非二元（MtX）。男娘不是 MtF。
- **雌堕**：色情作品和性幻想中的题材。指男性角色被塑造成女性化、顺从的形象，但仍然是男性。不是 MtF 身份。
- **药娘 / yn / xyn**：通常指正在或已经 HRT 的 MTF，但也可能指服用雌激素的 MtX 或男娘。不是能完整体现跨性别女性身份的词语。MtF 不都是药娘，药娘不一定是 MtF。

## HRT 相关

- **HRT**：激素替代疗法。通过药物调整体内激素水平，使身体特征更接近自己认同的性别。MtF HRT 以雌二醇为核心，通常配合抗雄激素。HRT 是身体层面的性别肯定医疗手段，不是跨性别身份成立的条件。
- **GAHT**：性别肯定激素治疗。比 HRT 更准确的现代医学术语，专门强调性别肯定目的。多数语境下与 HRT 指同一件事。
- **糖 / 吃糖**：社区隐语，“糖”泛指 HRT 药物，“吃糖”指使用 HRT 药物。
- **补佳乐 / 补**：补佳乐是一种雌二醇药物，“补”是社区简称。

## 医疗与法律文件

- **小证**：写有性别不安、性别认同相关诊断或治疗意见的病历、诊断书。常用于支持开始 HRT。具体要求和效力由医院、医生和使用场景决定。
- **大证**：正式的性别认同障碍、性别不安或相关诊断证明。用于申请 SRS 等医疗项目。具体要求由医院与地区规定。
- **SRS**：性别重置手术。改变生殖结构的性别肯定医疗手段，不是跨性别身份成立的条件。

## pass 与身份处境

- **pass**：性别表达在他人视角下被自然识别为自己认同的性别，而没有被识别为指派性别。是他人识别层面的结果，不是身份是否真实的判断标准。
- **鉴跨**：他人根据外在特征推测是否为跨性别者。通常带有冒犯性，社区内不受欢迎。
- **RLE**：以自己认同的性别在现实生活中持续生活。描述社会生活状态，不决定性别认同。
- **深柜**：长期隐藏跨性别身份，以指派性别身份生活。
- **反向深柜**：以符合性别认同的身份生活，但不公开自己是跨性别者。
- **出柜**：主动向他人公开跨性别身份。
- **爆柜**：身份在本人没有主动选择时被他人发现、传播或公开。

## 家庭与处境分类（社区俗称）

以下分类是社区非正式俗称，多用于自我描述，不应用于对他人贴标签。

- **家长党**：取得家长理解和支持。
- **家暴党**：因跨性别身份在家庭中遭受暴力、威胁、控制或强制干预。
- **年龄党**：在青春期较早阶段开始 HRT，身体可塑性更高。
- **天赋党**：先天身体条件较接近自己认同性别，较容易达到女性化效果。
- **天残党**：先天身体条件与认同性别差距较大，女性化过程受限更多。

::: warning ⚠️ 请谨慎使用
“天赋党”“天残党”虽常用于自嘲，但被他人用来评价时可能造成二次伤害。每个人的身体条件和过渡路径都是独特的。
:::

## 社会立场分类

- **友跨**：支持跨性别者，承认其性别认同，尊重称呼、身份、身体自主和同等权利。
- **反跨**：否定、贬低或排斥跨性别者的性别认同、身份、表达、医疗需求或平等权利。以出生指派性别、染色体、生殖器或所谓“生理性别”否定跨性别者实际性别，是常见反跨论述。

## 社群黑话

**开除跨籍**：以特定标准（如“是不是在 HRT”“够不够 pass”“是否符合刻板印象”）否认他人的跨性别身份。这种行为本身在社群内存在争议，本质是身份 policing，与“性别认同由本人决定”的原则相冲突。
