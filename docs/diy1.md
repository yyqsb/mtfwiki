# DIY 雌二醇凝胶指南

本页介绍自行配制雌二醇凝胶的常见配方、制作步骤和注意事项。内容整理自社区公开资料（包括 GitHub 上的多个 DIY 指南、公开专利文件及部分论文结论），供学习、研发参考。

**自制药品存在风险，其纯度、浓度和安全性无法得到保证。本文内容仅供个人学习、研发参考，不构成任何医疗建议。**

- 自制的雌二醇凝胶**不得用于医疗用途、不得销售**
- 使用前务必考虑自身情况，并**定期监测激素水平**
- 如果条件允许，**通过正规医疗途径获取药物始终是更安全的选择**
:::

## 核心安全警告

在进行任何操作前，请务必了解以下风险：

| 风险类型 | 说明 |
|---------|------|
| **原料风险** | 从非可信渠道购买的原料可能含有对人体有害的杂质 |
| **操作风险** | 卡波姆粉末吸入可能造成呼吸困难，接触眼睛可能引起不适；其溶液呈弱酸性，调节 pH 前避免接触皮肤和粘膜 |
| **产品风险** | 制成的凝胶有贮藏期，有效雌二醇含量会随时间下降（实验条件下 6 个月下降至 93%） |
| **健康风险** | 雌二醇凝胶本身是处方药，过量使用可能导致易怒、乳房不适、血栓风险增加等副作用 |
| **法律与道德** | 自制的雌二醇凝胶**不得用于医疗用途、不得销售**，仅供个人学习、研发使用 |

## 配方

以下是一种社区中较常见的配方，基于对公开专利的调整，推荐使用**体积比**计算，因为乳液瓶按压一次的量是固定的。

### 推荐配方（约 100ml）

| 原料 | 用量 | 备注 |
|------|------|------|
| **17-β 雌二醇** | 0.12% 及以上浓度 | 活性成分，建议搜索 CAS 号 `50-28-2` 购买，一定是 β 雌二醇 |
| **卡波姆 980** | 0.4–0.6%（质量比） | 凝胶基质，浓度越高越粘 |
| **三乙醇胺** | 与卡波姆质量比约 1.35:1 | pH 调节剂，用于使卡波姆凝胶化 |
| **水溶性氮酮** | 2% | 促渗剂 |
| **1,2-丙二醇** | 1.5% | 促渗剂 |
| **75% 乙醇** | 60 ml（体积比） | 溶剂兼促渗剂 |
| **纯净水** | 40 ml（体积比） | 溶剂 |

::: tip 💡 配方说明
- 氮酮与丙二醇作为复合促渗剂，以 **2% : 1.5%** 的比例混合可达最佳效果
- 卡波姆 980 耐离子性和耐剪切性较好，是雌二醇凝胶配方中出现频率较高的型号
- 酒精浓度使用 **60% 体积比**（约 54% 质量比），基于论文和专利的推荐
- 雌二醇浓度建议根据自身激素检查结果调整，保持在**一次涂抹 1ml 左右**即可
:::

## 制作步骤

以下步骤综合了多个来源的操作流程，采用**先溶解卡波姆**的方法，比原文方法更易溶解。

### 第一步：溶解卡波姆（凝胶基底）

向烧杯加入 40 ml 纯净水。用毫克称量取对应量的卡波姆（**注意安全**），建议**分多次**量取后**多次加入**，避免高速搅拌形成气泡，也不要一次全加进去不搅拌，否则容易形成“水球”。

完成后待卡波姆溶胀 **24–48 小时**，期间可多次搅拌均匀，搅拌至透明稍白溶液。**至少需要浸泡 8 小时**。

::: tip 💡 加速溶解
可以且推荐使用**热水**溶解，卡波姆在 104°C 下加热 2 小时不影响其增稠性。使用热水时请小心热液飞溅。
:::

::: warning ⚠️ 卡波姆操作安全
卡波姆不得入眼、不得吸入，请尽可能做好安全防护（**口罩、护目镜**）。若吸入请立即移至通风良好的地方。
:::

### 第二步：溶解雌二醇与促渗剂

在**另一个容器**中，加入 60 ml 75% 乙醇，加入雌二醇，搅拌至完全溶解。可以适当加热至 **40°C 左右**加速溶解。

然后使用移液胶管或其他工具加入丙二醇和水溶性氮酮。**尽可能多地搅拌**，确保完全溶解，可以静止后过一会接着继续搅拌。

### 第三步：混合与调节 pH

将第二步的功效溶液加入第一步的卡波姆基底中，搅拌均匀。

加入三乙醇胺，搅拌至溶液变为**无色透明凝胶态**。三乙醇胺与卡波姆的质量比约为 **1.35:1**，请根据卡波姆用量自行调节。

::: warning ⚠️ 检查 pH 值
完成制作后**应该检查溶液 pH 值**，避免完成品刺激皮肤。请注意 pH 笔无法测量凝胶的 pH 值，建议使用 **pH 试纸**。
:::

### 第四步：转移与装瓶

将凝胶转移至乳液分装瓶中。转移完成后静置一段时间后即可使用。

::: tip 💡 凝胶的质地
制成的凝胶**不一定是透明的**。只要做到卡波姆完全溶解、无可见白色水球、浸泡时间到位即可。雌二醇可能部分未完全溶解，只要溶液整体透明即可（如“健民”说明书指出本品为乳白色凝胶）。
:::

## 不同配方与吸收效果参考

::: warning ⚠️ 个体差异显著
DIY 凝胶的效果存在显著的**个体差异**。即使是相同的配方，不同人的吸收效果也可能相差**一倍以上**。
:::

| 配方 / 浓度 | 用量与部位 | 检测结果（雌二醇） | 检测结果（睾酮） |
|------------|-----------|------------------|----------------|
| 4.8 mg/mL | 1.25g，每晚涂抹于大腿后内侧 | 12 小时后：**103 pg/mL** | — |
| 6.0 mg/mL | 1.5g，每晚涂抹于大腿后外侧 | 18 小时后：**50 pg/mL** | 睾酮回升，出现晨勃 |

**关键发现**：血液中的雌二醇浓度与睾酮水平之间**没有直接的正比关系**。一位使用者曾在雌二醇 60 pg/mL 的情况下，睾酮仅有 0.4 ng/mL。

## 使用注意事项

### 涂抹部位

- 建议涂抹于**大腿内侧、手臂、腹部**等皮肤较薄处
- **不应涂抹于粘膜**——可能受酒精刺激
- **不应涂抹于乳房周围**——可诱发乳腺癌

### 采血污染

::: danger ⚠️ 采血前注意
如果在采血前，将凝胶涂抹在了**采血点周围的皮肤上**，可能会导致雌二醇检测值**错误地偏高**。
:::

### 贮藏

- 凝胶有贮藏期，雌二醇含量会随时间下降（实验条件下 6 个月下降至 93%）
- 应**避光贮存**成品
- 尽可能做到“用多少做多少”

### 促渗剂的选择

除了配方中的乙醇、氮酮和丙二醇，还可以使用**油酸、亚油酸、月桂醇、尿素、水杨酸、薄荷醇**等作为促渗剂。使用**复合促渗剂**优于单一促渗剂。

## 常见问题

### Q：凝胶可以做成透明的吗？

凝胶**不一定是透明的**。只要卡波姆完全溶解、无可见白色水球、溶液整体均匀即可，乳白色是正常现象。透明与否取决于卡波姆的类型和浓度。

### Q：可以不用乙醇吗？

乙醇在配方中同时充当溶剂和促渗剂。如果去掉乙醇，雌二醇的溶解度和皮肤吸收率都会大幅下降。不建议用其他溶剂完全替代乙醇。

### Q：可以用其他类型的卡波姆吗？

卡波姆有多个型号（如 940、980、974P 等）。980 是社区配方中较常用的一种，其他型号也可以尝试，但需要调整用量以达到相似的粘度。980 在公开的工业配方中出现频率更多，且厂家介绍中直接指出其适用范围包含雌二醇凝胶。

### Q：为什么不同人的检测结果差那么多？

皮肤吸收率受个体皮肤状况、涂抹部位、涂抹面积、是否揉搓、停留时间、体脂率、是否服用其他药物等多种因素影响。**定期抽血检测是唯一可靠的评估方式**。

### Q：制作时需要注意什么？

- **卡波姆操作**：戴口罩和护目镜，避免吸入粉末
- **酒精挥发**：搅拌时注意乙醇挥发，容器尽量加盖
- **pH 检查**：制作完成后务必用 pH 试纸检查，确保不会刺激皮肤
- **不要一次做太多**：凝胶有贮藏期，用多少做多少
