## 配方

**可制成 20 片贴片。**

| 原料 | 用量 | 说明 |
|------|------|------|
| **雌二醇** | 8 mg | 4 片 × 2 mg 仿制药片，原样使用 |
| **瓜尔胶** | 1.2 mL | 约 1/4 茶匙 |
| **水** | 3.1 mL | 约 5/8 茶匙 |

作者选择这个配方是因为：

- **瓜尔胶**：便宜、随处可买、人们本来就经常吃
- **不用秤**：并非每个人都有足够精密的秤称量微小原料量
- **难度**：不会超过制作新鲜意大利面，只需要常见的家用物品

## 制作步骤

### 第 1 步：研磨

把片剂研磨成细粉。

**工具**：干净的陶瓷研钵和研杵，或刀 + 药瓶 + 餐盘

**技巧**：
- 可以先用刀或分药器把片剂分成小块
- 用药瓶盖的一端朝下，把碎粒压在餐盘上磨细
- 刚开始压碎时，先用便签纸盖住药片碎块，防止碎片飞溅

**目标状态**：细、软、均匀的粉末。

### 第 2 步：混合

量取瓜尔胶，与药片粉末充分混合。

**工具**：1/8 茶匙量勺（后续量水也用同一把）

**目标状态**：两种粉末形成平滑、均匀的混合物。

### 第 3 步：加水

把水加入干性原料中，**极其充分地混合**。

**方式**：
- 研钵：直接用研杵搅拌、涂抹、研磨
- 盘子上：像碾药片一样用药瓶反复抹开、聚拢
- 也可以用手或勺背

**调整**：太干加水，太湿继续揉捏或稍微晾干。

**目标状态**：有弹性、光滑、可塑，不会散开，能够干净地卷起。

### 第 4 步：分份

分成大小相等的份量。

**技巧**：
- 搓成一条小长条，按所需剂数切分
- 各份通常会有大有小 → 最大和最小合并，均分成两份，反复调整至均匀

**目标状态**：大小相同或尽可能接近的小块面团状混合物。

### 第 5 步：压片

把各小块塑造成扁平圆片。

**模具**：金属垫圈中央的孔

**技巧**：
- 垫圈孔所容纳的量恰到好处 → 无需预先分份，填满推出即可
- 不用模具时，可用硬币或其他厚度已知的小物件作参照

::: warning ⚠️ 厚度很关键
- **太薄**：干燥时会卷曲，且维持不到 24 小时
- **太厚**：显得笨重，且持续时间远超 24 小时
:::

**目标状态**：
- 扁平、圆形、厚度均匀、不透明
- 厚度 ≤ **1.8 mm**（约 70 密耳 / 0.070 英寸 / 略小于 5/64 英寸）
- 直径约 **9.5 mm**（约 3/8 英寸）

### 第 6 步：干燥

让它们完全干燥。

**方式**：放在盘子上过夜，置于不受打扰的地方

**变化**：干燥过程中会明显收缩

**目标状态**：
- 扁平、圆形、坚硬而有韧性、不透明
- 厚度约 **1.1 mm**（约 3/64 英寸）
- 直径约 **6.5 mm**（略大于 1/4 英寸）

干燥后装入药瓶保存。

## 使用方法

### 操作流程

1. 早餐后刷牙
2. 把一片贴片放在舌头上
3. 将它推到上牙龈前侧，贴在**犬齿与切牙之间**
4. 每天左右交替
5. 贴上后约 **一小时内避免进食或饮水**
6. 贴片逐渐吸水 → 变成平滑凝胶团 → 约 24 小时后完全溶解

::: warning ⚠️ 两个容易导致脱落的情况
- 贴上后一小时内喝水
- 擤鼻涕（与贴上后经过多久无关）

只要小心一点，这两件事都可以做。
:::

### 实际体验

| 场景 | 是否可行 |
|------|---------|
| 进食、饮水 | ✅ |
| 刷牙、漱口 | ✅ |
| 接吻、口交 | ✅ |
| 长时间说话 | ✅ |
| 用吸管喝水 | ✅ |
| 食物卡在贴片上 | 不太会 |
| 味道 | 没有明显味道 |
| 吸水前轻微不适 | 偶尔，很快消失 |

**脱落处理**：
- 尚未充分吸水前脱落 → 用舌头推回原位，暂时不碰它会重新粘住
- 吸水后脱落 → 较难重新贴回；通常直接换一片新的

**不同贴法对比**：
- **下牙龈**：更容易移位（不推荐）
- **睡前贴**：溶解不理想，感觉更厚重（不推荐）
- **早晚各一次（12 小时贴片）**：适合忘记早晨剂量或需要替换时

### 贴片是什么

雌二醇被包在一片**坚韧、致密的瓜尔胶圆片**中。吸水膨胀后，与口腔内壁摩擦，随着贴片逐渐侵蚀，雌二醇被释放出来，通过口腔黏膜进入血液。

学术上可能称为：**用于雌二醇控释或缓释的颊黏膜黏附给药系统**。

## 结果

作者每天一次使用约 **0.375 mg 雌二醇**，**未使用任何抗雄激素**，血检结果如下：

| 时间点 | 雌二醇（E2） | 睾酮（T） |
|--------|------------|----------|
| 停用 HRT 时 | 69 pmol/L（19 pg/mL） | 35 nmol/L（1009 ng/dL） |
| 给药后 6 小时 | 434 pmol/L（118 pg/mL） | 6.9 nmol/L（199 ng/dL） |
| 给药后 24 小时 | 272 pmol/L（74 pg/mL） | 14 nmol/L（404 ng/dL） |

::: tip 💡 为什么这个结果值得关注
- 与医生开的口服剂量（4 mg/天）相比，**只需 1/10 的剂量**就能达到“正常”血液雌二醇水平
- 一瓶药片可制成约 **10 个月**的贴片用量
- 贴片效果稳定，作者本人长期使用，没有出现明显问题
- 最糟的情况只是偶尔脱落，过去几个月仅发生五六次
:::

制作一批（20 片）大约需要 **半小时**，所需物品不昂贵也不罕见。

## 为什么值得尝试

### 现有剂型的局限

| 剂型 | 优点 | 缺点 |
|------|------|------|
| **贴片** | 控释好，血药浓度稳定，每日剂量小（0.1–3 mg） | 很贵，使用麻烦 |
| **片剂（吞服）** | 便宜、方便 | 首过效应，需更高剂量（4–8 mg），影响肝脏 |
| **舌下含服** | 避开首过代谢 | 血药浓度迅速升又迅速降，难以可靠测量 |
| **注射** | 避开首过代谢，水平渐进可预测 | 麻烦，存在短缺和处方问题 |

### 这个方案的核心思路

雌二醇在工业生产中**既容易制造又便宜**，世界上已有大量雌二醇以片剂形式存在。与其在家合成（需要纯化和定量，设备要求高），不如**寻找一种更好的使用方式**，利用已有的资源。

::: tip 💡 关键收益
- 每日所需剂量仅为口服的 **1/8 到 1/10**
- 一瓶药片可制成 **约 10 个月**的贴片
- 血液雌二醇水平**更稳定**
- 制作**几乎任何人都能完成**：不用奇怪原料、不用专用设备、不昂贵
:::

### 作者的制作历程

- **2019 年末**：完成资料研究，确定方向
- **2020 年大部分时间**：摸索配方，自我测试
- **2020 年 3 月以来**：未通过任何其他方式使用雌二醇
- **一开始**：每次只做两剂，剂量难以准确量取
- **起初剂量**：0.25 mg/天
- **尝试 0.5 mg/天**：感觉药效过强、来得突然 → 降回 0.25 mg
- **第一次血检后**：提高 50%
- **第二次血检后**：数值大致改善相同比例 → 此后不再调整

**方法说明**：
- 每次改变配方或流程后，**维持新方案约 2 周**
- **每次只改变一个因素**
- 用日志记录：批次、尺寸、形状、贴上时间、溶解时间

**规律**：
- 增加雌二醇 → 药效更强
- 增加瓜尔胶 → 贴片更厚，持续更久
