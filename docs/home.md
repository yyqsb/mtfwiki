# Callyourzephyr's MtF 资源站

<div class="trans-tag">🏳️‍⚧️🍥 Trans Pride</div>

一个整理跨性别女性（MtF）医疗知识、实用工具和社区资源的站点。

如果你是 MtF，或者正在怀疑，这里可以作为一个起点。所有内容都基于公开资料整理，供学习和参考。

::: danger ⚠️ 重要声明
本站内容**不构成医疗建议**。所有 HRT 相关药物、剂量、检查建议，都必须在专业医生指导下进行。请勿根据本站内容自行用药或调整方案。

具体问题请咨询专业医生。本站仅作知识整理和工具提供。
:::
