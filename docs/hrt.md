# HRT入门

如果你正在考虑开始激素替代疗法（HRT），但不知道从哪里下手，这篇指南会带你走过完整流程——从自我评估到开始用药，每一步都告诉你该做什么、去哪里做、需要注意什么。

::: danger ⚠️ 重要声明
本文仅为流程性指南，不构成医疗建议。HRT 必须在专业医生指导下进行。所有用药方案、剂量调整、检查频率均需由你的主治医生根据你的具体情况决定。请勿自行用药或照抄他人的方案。
:::


## 第一步：自我评估与心理准备

在开始任何医疗步骤之前，你需要先回答自己几个问题。

**1. 确认自己的需求**

HRT 的目的是让身体特征更接近你的性别认同。在开始之前，建议你：

- 了解 HRT 能做什么、不能做什么。激素并非无所不能的“魔法”，它不能改变骨骼结构、声音（MtF 声音需要额外训练）、身高，也不能替代社会过渡和心理适应。
- 建立理性的心理预期。乳房发育、脂肪分布改变等效果需要数月到数年才能显现，且因人而异。
- 确认你是否有持续的、稳定的性别认同需求。

**2. 了解 HRT 的效果与时间线**

MtF HRT 的典型效果和时间线大致如下（具体因人而异）：

| 效果 | 预期开始时间 | 预期最大效果 |
|------|------------|------------|
| 乳房发育 | 3–6 个月 | 2–3 年 |
| 体脂重新分布 | 3–6 个月 | 2–5 年 |
| 皮肤变软、变细 | 3–6 个月 | 1–2 年 |
| 肌肉量减少 | 3–6 个月 | 1–2 年 |
| 体毛变细、生长变慢 | 6–12 个月 | 3 年以上 |
| 性欲变化 | 1–3 个月 | 1–3 年 |

::: warning ⚠️ 注意
HRT **不能**改变已经变声的声带、不能改变骨骼结构（如身高、肩宽、髋宽）、不能消除已经长出的面部毛发（需要激光脱毛或电解脱毛）。
:::

**3. 心理准备**

- HRT 是一个**长期甚至终身**的过程。如果选择进行 HRT，通常需要持续用药，停药后部分效果会逆转（如脂肪分布、肌肉量），部分效果会保留（如乳房发育）。
- HRT 可能会影响**生育能力**。如果你有生育计划，建议在开始 HRT 前咨询医生关于冻存精子的事宜。
- HRT 可能带来情绪波动。这在调整期比较常见，但如果你有情绪管理方面的困扰，建议提前建立心理支持系统。

## 第二步：寻找医生与就诊

**1. 就诊科室**

在国内，可以开具 HRT 处方的科室主要有：

- **内分泌科**：最直接的途径。部分医院的内分泌科有跨性别友好医生。
- **精神科 / 心理科**：部分医院要求先获取“易性症”或“性别不一致”的诊断证明（俗称“开证”），之后才能转诊到内分泌科开药。
- **跨性别专科门诊**：部分大城市的三甲医院设有跨性别专科门诊，可以一站式完成评估和处方。

::: tip 💡 就诊前准备
- 提前打电话或在医院官网查询，确认该科室是否接诊跨性别患者、是否需要提前预约、是否需要诊断证明。
- 如果医院要求诊断证明，需要先到精神科或心理科就诊。诊断通常需要多次面诊，医生会评估你的性别认同是否持续、稳定，以及是否伴随性别不安（GD）。
- 就诊时可以带上你整理好的自我描述、既往就诊记录（如有）、以及你希望了解的 HRT 相关问题。
:::

**2. 就诊流程（国内常见路径）**
精神科/心理科就诊 → 获取诊断证明（如需） → 内分泌科就诊 → 开具检查 → 医生评估 → 开具处方 → 定期复查

部分医院实行 **“知情同意”模式**（informed consent），即不需要精神科诊断证明，医生在充分告知 HRT 的风险和效果后，如果你表示理解并同意，就可以直接开具处方。但目前国内实行这一模式的医院较少，具体需咨询当地医院。

## 第三步：开始前的检查

在开具 HRT 处方之前，医生通常会要求你完成一套**基线检查**，用于评估你的身体基础状态，并作为后续监测的参照。

**常规检查项目包括：**

- **激素六项**：雌二醇（E2）、睾酮（T）、孕酮（P）、促卵泡激素（FSH）、促黄体生成素（LH）、泌乳素（PRL）
- **肝功能**：ALT、AST、GGT、总胆红素等
- **肾功能**：肌酐、尿素氮等
- **血脂**：总胆固醇、甘油三酯、HDL、LDL
- **空腹血糖**
- **血常规**
- **凝血功能**：D-二聚体等

::: warning ⚠️ 特别提醒
如果你有**吸烟**习惯，务必在就诊时告知医生。吸烟会显著增加雌激素相关血栓（VTE）的风险。医生可能会建议你在开始 HRT 前戒烟，或选择经皮给药（贴片/凝胶）以降低血栓风险。
:::

## 第四步：开始用药

**1. 常用药物**

MtF HRT 的核心是**雌二醇**，通常配合**抗雄激素**使用。

| 类别 | 常用药物 | 常见剂量范围 |
|------|---------|------------|
| 雌激素 | 戊酸雌二醇（口服/舌下） | 2–6 mg/天 |
| 雌激素 | 17β-雌二醇（舌下/含服） | 1–4 mg/天 |
| 雌激素 | 雌二醇凝胶（经皮） | 1–3 揿/天 |
| 雌激素 | 雌二醇贴片（经皮） | 0.1–0.2 mg/24h |
| 抗雄激素 | 螺内酯（口服） | 50–200 mg/天 |
| 抗雄激素 | 醋酸环丙孕酮（CPA，口服） | 12.5–50 mg/天 |
| 抗雄激素 | 比卡鲁胺（口服） | 25–50 mg/天 |

::: tip 💡 经皮 vs 口服
经皮给药（凝胶/贴片）绕过肝脏首过效应，对肝脏的负担更小，血栓风险也相对更低。如果你有肝功能异常、吸烟史、或血栓风险因素，医生可能会优先考虑经皮给药。
:::

**2. 剂量递增原则**

HRT 通常从**低剂量**开始，逐步递增，以模拟自然青春期的激素变化节奏。这有利于乳房等组织的自然发育，也能让身体更好地适应。

- 雌激素通常每 4–8 周递增一次，根据身体反应和检查结果调整。
- 抗雄激素的剂量也通常从低剂量开始，根据睾酮水平调整。

**3. 给药方式与服用时间**

- 口服药建议**舌下含服**（如果医生允许），可以提高吸收率，减少肝脏负担。
- 经皮凝胶通常每天涂抹一次，涂抹在清洁、干燥的皮肤上（如大腿内侧、腹部），避开乳房区域。
- 贴片通常每 3–4 天更换一次。
- 抗雄激素的服用时间需遵医嘱。

::: tip 💡 工具推荐
你可以用本站的 [激素计算工具](/docs/tools/hormone.md) 来换算单位、生成服药时间表，以及查看激素浓度曲线。
:::

## 第五步：定期监测与调整

开始 HRT 后，**定期复查**是确保安全和效果的关键。

**1. 复查频率**

- **第一年**：每 **3 个月** 复查一次
- **第二年及以后**：如果各项指标稳定，可延长至每 **6 个月** 一次
- **长期稳定后**：部分指南建议可延长至每年一次

**2. 复查项目**

每次复查通常包括：

- 激素六项（重点看雌二醇和睾酮的水平）
- 肝功能、肾功能
- 血脂、血糖
- 血常规
- 凝血功能（如有需要）

**3. 目标范围**

- **雌二醇（E2）**：100–200 pg/mL（约 367–734 pmol/L）
- **睾酮（T）**：< 50 ng/dL（约 < 1.7 nmol/L）

::: warning ⚠️ 不要自行调药
如果检查结果不在目标范围内，**不要自行增加或减少剂量**。应带着检查结果去复诊，由医生根据你的具体情况调整方案。自行调药可能导致激素水平波动过大，或引发不必要的副作用。
:::

## 常见问题

### Q：HRT 多久能看到效果？

乳房发育通常在 3–6 个月开始，2–3 年达到最大效果。体脂重新分布和皮肤变化在 3–6 个月开始，1–2 年比较明显。每个人的反应速度不同，不要和别人比较。

### Q：HRT 会影响寿命吗？

规范用药的 HRT 不会导致“活不过 30”这种结果。寿命受多种因素影响，包括遗传、生活方式、心理健康和社会支持。跨性别群体中存在的健康差异，更多来自社会压力、医疗资源可及性和歧视，而不是 HRT 本身。详见 [常见刻板印象与误解](/docs/guide/myths.md)。

### Q：可以 DIY 吗？

DIY 指的是自行获取药物、无医生处方或监督进行 HRT。DIY 的风险主要来自不规范用药（如极端过量、不检查、不监测）。如果你因医疗资源不可及而考虑 DIY，建议你至少做到：**定期抽血检查激素水平、肝肾功能**，并尽量参考公开的循证指南。但本站始终建议通过正规医疗途径获得 HRT。

### Q：HRT 期间可以怀孕吗？

HRT 不是避孕手段。MtF 在进行 HRT 期间，睾酮水平会被抑制，但**不代表绝对不会产生精子**。如果你有生育计划，建议在开始 HRT 前咨询医生关于冻存精子的事宜。

### Q：停药后会怎样？

停药后，部分效果会逆转（如脂肪分布、肌肉量、性欲），部分效果会保留（如乳房发育）。如果你决定停药，建议与医生讨论逐步减量的方案，而不是突然停药。
